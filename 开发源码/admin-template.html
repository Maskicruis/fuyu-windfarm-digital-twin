后台编辑与交付方式

  1. 选择单位工程、功能模块及画幅。
  2. 点击画布或组件树选中元素；场景工具条等可作为独立组件移动。
  3. 在“布局”调整位置与尺寸；在“内容”修改内部文字、数字、日期或提示。
  4. 点击“交互预览”检查效果；保存草稿后，点击“发布前端”。
前端与后台分离

frontend.html 仅展示已发布内容；admin.html 是唯一编辑入口。通过本地服务运行时，发布会写入磁盘配置并更新展示端。双击 HTML 的离线方式会导出独立展示文件，请按下载提示保存。

所有画幅、单位工程和功能模块分别保存。施工模拟逻辑与原业务资料沿用原演示；文字修改属于展示内容配置。
