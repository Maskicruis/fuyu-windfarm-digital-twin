V10.0 · 工程知识库与系统管理

前台顶部“知识库”支持导入 PDF、TXT/MD、DOCX、XLSX 和图片，按工程、分组、对象及工序关联。关闭资料窗口后后台仍继续解析；失败或缺少引擎会明确显示。扫描资料需要在“解析设置”配置本机 MinerU。

同一悬浮智能体支持资料增强、仅资料库检索和通用对话。PDF 引用跳到真实页码，文本和 Office 按真实解析片段定位；有效关联对象可以明确点击定位三维场景。已完成会话保存在本机，可从“本机对话”恢复。

后台“系统管理”提供服务概览和数据接口配置。GET JSON 接口经测试及字段校验后仅应用到草稿，检查发布后才影响展示。GitHub 管理完整程序、源码和文档，不提交运行 data、导入原件、索引、会话或密钥；迁移更新时务必保留 data。

详见同目录 README.md。验证：Python97项、DOM67组467断言通过；浏览器视觉自动验证因工具无法确认当前页面地址而停止。真实模型和 OCR 仍需用自己的配置测试。

场景播放与 DeepSeek 设置

项目全览右上方点击“播放场景”，全场镜头开始缓慢巡游，风机叶轮同步转动；再次点击暂停。手动操作、切换工程、打开设置或隐藏页面会暂停，重新播放需主动点击。此控制独立于施工模拟，不改变工序和现场填报。

前台、后台顶部均有“设置”。通过启动脚本打开本机服务，在设置中填写 DeepSeek API Key，选择模型并保存，然后点击“测试已保存配置”。默认使用 DeepSeek Flash，也可切换 DeepSeek V4 Pro；可配置回复长度、记忆轮数、温度、深度思考及是否自动带入场景上下文。模型接入方式参考 DeepSeek 官方接口文档。

悬浮智能体自动跟随当前单位工程、对象位置、所查看工序，携带对应工序表的施工资源、工艺、质量要点及已配置进度；可围绕上一条回答继续追问。切换对象或会话会停止本页旧请求，避免迟到回答混入当前范围。危大工程、验收标准、质量通病继续通过界面直观提示查看。

密钥使用 Windows DPAPI 加密，保存在当前 Windows 账户的本地用户目录，不进入 G 盘交付包、HTML、布局 JSON 或浏览器存储。普通参数在 data/settings.json。换 Windows 账户或移动项目路径后，应重新填写密钥。已完成会话保存在本机，可在会话列表恢复；不自动上传扫描件原件。停止按钮会结束本页等待，已提交的模型请求可能仍由服务端完成。

初次交付未配置 API Key。请自行在设置中填写并完成真实连接测试；未配置或连接失败会显示具体提示，不切换为本地预设回答。直接双击 HTML 的离线方式可播放场景、调整布局，模型对话需要本机服务和网络。

日常推荐入口：在文件夹中双击 启动控制后台.cmd，需要展示时双击 打开前端展示.cmd。脚本自动打开实际地址，通常无需手填 URL。启动器会精确校验 revision 9.1 和当前工作目录，只复用同一目录的当前版本服务，不会连接旧服务。默认尝试 8779；被占用时自动尝试 8782–8791。关闭浏览器不会停止本地后台服务。

01两个交付物，各自承担什么

frontend.html · 纯展示前端

显示已发布的界面与展示数据配置，保留模型浏览、工程切换、工序查看、资料查询及悬浮智能体交互。扫描件可查询和预览原件。没有后台入口、登记按钮、修改登记功能和编辑边框。

admin.html · 独立控制后台

左侧是工程、模块和组件树，中间是实时预览，右侧是布局、样式、内容与数据属性。界面布局、文字、样式及对象展示数据编辑为草稿，确认后发布；扫描件登记、元数据和归档标记直接保存。

默认地址示例：http://127.0.0.1:8779/admin.html 与 http://127.0.0.1:8779/frontend.html；实际端口以启动脚本打开的页面和终端提示为准。服务只监听本机，通过 Python 标准库运行。

02五步完成一次修改

  1. 启动后台

    双击 启动控制后台.cmd，确认顶部显示“本地服务已连接”。画布会自动重试连接；18 秒仍未就绪时显示错误和“重载画布”，已保存草稿保留。若直接双击 admin.html，会进入离线编辑，真实扫描件存取仍需要本地服务。

  2. 选择工程、模块和画幅

    左侧选择风机、道路、集电线路或升压站，再选“施工模拟演示、施工管理辅助、施工资料记录”。上方画幅可选 1920×1080、1440×900、1280×720 或 390×844。项目全览使用独立页面范围。

  3. 选中整卡、内部控件或一段文字

    在“选取与编辑”状态下点击画布，或从左侧组件树选择目标。可用“组件 / 文字 / 全部”和搜索框快速查找。要点击业务按钮、切换具体对象或工序，先切换到“交互预览”，完成操作后再返回编辑。

  4. 修改位置、样式和内容

    拖动选中边框移动位置，拖动右下角缩放；也可以在“布局”中输入 X、Y、宽度与高度。使用“样式”调整字号、颜色、背景、边框和透明度；使用“内容”编辑内部文字及输入提示；使用“数据”修改当前对象的展示数据。

  5. 预览、保存草稿并发布

    点击“交互预览”检查按钮、文字遮挡、模型浏览和资料筛选。草稿会自动保存，也可点“保存草稿”。界面修改确认后点“发布前端”，再点“打开展示”查看不含编辑界面的前端。资料登记另见下节，不需要执行界面发布。

03工具条与其他内部 UI 怎样移动

场景说明、场景工具条等已经作为独立组件登记。选中它们即可单独调整，不必连同整个中间工作区一起移动。

定位方式适合什么坐标含义
相对父组件卡片中的标题、按钮、数字、小图形和说明文字；希望随父组件移动的内容。X、Y、宽高以父组件为参照。保存使用相对比例，后台显示对应 px 数值。
独立定位到画布场景工具条、独立说明窗，以及需要跨过原面板边界移动的整卡。X、Y、宽高以整个预览画幅为参照，可以移到原来的父框之外。SVG 内部文字及图形仍按其局部坐标调整。
调整场景工具条的例子：选择“场景操作工具”组件 → “布局” → 选择“独立定位到画布” → 拖动到模型右侧或下方 → 调整宽高 → 进入“交互预览”检查遮挡 → 发布。只想改图里的“填隙碎石路面”“检测点”等文字，可在“内容”列表中选择对应文字。

叠放关系由“层级”控制，数值越大越靠上；“隐藏所选元素”不会把它从组件树移除。误改后可用“撤销”“重置所选”，或“恢复当前页面默认设置”。

04文字、样式与对象数据分开编辑

属性页可修改内容使用要点
布局定位方式、X/Y、宽高、对齐、层级、显隐。整卡与内部元素可分别选择；选择树中的上层组件可移动整组内容。
样式字号、文字颜色、面板背景、边框颜色与粗细、圆角、不透明度。选中文字只改该段文字；选面板则修改该面板。SVG 文字也能编辑字号与颜色。
内容标题、说明、按钮名称、状态文字、表头与单元格、SVG 文字，以及 title、placeholder、辅助说明。选择组件后会列出内部文字，可搜索和翻页。输入按普通文字处理，不接受 HTML 代码。
数据当前对象名称、位置/桩号、实际与计划完成比例、已报工序编码、施工状态；也可编辑组件内数值及高级配置 JSON。对象展示数据单独绑定到当前对象。实际、计划、差值与进度条共用数据源，数值修改会同步图形。

共享文案

例如面板标题、“实际填报”“计划完成”等标签，属于当前页面的文案配置。改变名称不会改变按钮原有的功能键。

当前对象 / 工序

名称、位置、已报阶段和工序相关提示会按对象或工序范围识别。切换对象后，应检查右侧显示的范围，再应用修改。

对象展示数据

“数据”页的实际/计划比例等字段会同步该对象在不同模块的展示。它们是本地演示配置，不回写现场系统。

功能归属保留内容编辑与使用
施工管理辅助 · 直接界面实际 / 计划进度、当前阶段及位置、程序执行记录，以及质量通病、危大工程、验收标准的直观提示。提示卡片可在后台“内容”中配置。原工序表未单列质量通病库，因此初始为“待配置”；名称、表现部位和防治措施需按项目补充。
独立悬浮智能体施工资源（劳动力、材料、机械、设备）、标准工艺、质量要点。通过悬浮对话窗口查询；每项内容使用一个交付入口。通病、危大工程、验收标准到界面卡片查看，不重复设置问答栏目。

需要修改进度时，优先使用“数据”页的“实际完成”“计划完成”。已绑定的进度文字也会更新同一数据源；普通日期或状态文案的覆盖，不代表现场记录已被更新。已报工序编码应来自当前单位工程的工序目录。

05按单位工程登记真实扫描件

后台顶部画布工具栏的 资料登记 会切换到当前单位工程的“施工资料记录”和“交互预览”；当前为项目全览时，默认进入升压站。登记完成后，需要调整 UI 时切回“选取与编辑”。

  1. 选择工程分支和归档目录

    资料按单位工程归档。升压站需手动选择“土建工程”或“安装工程”；对象、区段及施工工序只是可选关联条件。切换浏览工序不会清空单位工程档案。

  2. 选择扫描件并填写登记信息

    点击“登记扫描件”，选择 PDF、JPEG（.jpg / .jpeg）、PNG 或 WEBP，单文件不超过 40 MiB。填写名称、编号目录、档号、版本、形成日期、关联对象/工序和备注，点击“保存扫描件与登记”。只有本地服务方式支持实际保存。

  3. 预览原件、修改登记和归档标记

    在台账选择文件，点击“预览原件”查看实际 PDF 或图片。后台“修改登记”可更正文案、分类、版本和关联，并在“已登记 / 已标记归档”之间切换；归档标记可撤回。原文件名及原件不由元数据编辑改写。

06保存草稿、发布与恢复历史

编辑后台草稿→交互预览→发布前端→前端展示
操作写到哪里是否改变展示前端
自动保存 / 保存草稿本地服务模式写入 data/draft.json；浏览器保留本机草稿备份。不会。前端继续使用上一次已发布版本。
发布前端写入 data/published.json、展示配置.json，并更新 frontend.html 内置配置。会。HTTP 展示页面自动读取最新发布；重新双击前端文件也可看到已发布配置。

界面配置按单位工程、模块和屏幕类型隔离：桌面宽度大于 1200px，平板为 901–1200px，窄屏为 900px 及以下。同一屏幕类型内的位置与尺寸按相对比例保存。对象展示数据则按对象识别，不因画幅或模块切换而另造一份数值。

07离线方式、备份与换电脑

本地服务方式

使用启动脚本打开后台。草稿和发布记录直接落盘，适合日常长期编辑。备份时复制整个交付文件夹，尤其保留完整 data（包含扫描件登记表与原件）、两个 HTML 和 展示配置.json。

双击 HTML 的离线方式

双击 admin.html 可离线编辑 UI。顶部显示“离线编辑”，按钮变为“导出展示前端”；下载带配置的纯展示 HTML，由你选择保存位置。扫描件上传、原件查询与持久化依赖本地服务，不能靠双击 HTML 完成。

离线编辑不会自动把下载文件写回当前 G 盘的 frontend.html。换电脑演示可直接使用导出的展示文件；继续编辑可导出配置 JSON，再在另一台电脑的后台导入。V8 的旧布局配置与 V9 系列的完整内容配置采用不同结构，V10.0 导入器接受 version:2 界面配置。

文件夹内的“开发源码”和测试用于后续维护。正常展示与后台操作无需手工修改源码。启动本地服务需要可用的 Python 3；当前启动脚本会先查找已配置的本机运行时，再查找系统 Python。

08常见问题

为什么前端里找不到“布局控制台”？
这是前后台分离的预期行为。前端只展示，所有调整进入 admin.html。日常使用启动脚本进入服务方式后台。
点击预览中的按钮只是选中，不能切换对象？
当前处于“选取与编辑”。先点中间工具栏的“交互预览”，执行对象、工序或资料筛选等原有操作，再返回编辑状态调整页面。
怎样修改智能体里的标题、欢迎语、输入提示？
先点左侧“展开智能体”，再从组件树中选择智能体或内部文字。输入框占位文字在“内容 → 提示与输入说明”中修改。回答、来源等动态内容需要在对应状态显示后选择。
改了后台，现场展示为什么没有变化？
先看顶部保存状态，再点“发布前端”。保存草稿只改变后台预览。HTTP 展示页会读取新发布；若前端已经以文件方式打开，重新打开或刷新它。离线后台则需要使用本次导出的展示 HTML。
隐藏组件后，怎样找回来？
在左侧组件树中搜索名称，选中后取消“隐藏所选元素”。也可使用“重置所选”；需要恢复整页时使用“恢复当前页面默认设置”。
“恢复历史”会直接覆盖当前展示吗？
不会。恢复到后台草稿后先检查预览；只有再点“发布前端”，展示才切换到该版本。
画布一直显示载入，或启动器遇到端口占用？
画布会自动握手重试；18 秒无回应会显示可操作的错误面板，点击“重载画布”。推荐从 CMD 脚本启动。启动器只复用 revision 9.1 且工作目录一致的服务；8779 被旧服务或其他程序占用时，会自动选择 8782–8791。使用脚本打开的实际页面，通常无需手填地址。若所有候选端口不可用或缺少 Python，按终端提示处理。
资料保存后还要发布吗，关闭浏览器会丢失吗？
资料直接写入本机 data/documents，无需发布；重开服务可恢复。界面布局、文字和对象展示数据仍需要先保存草稿，再发布。关闭浏览器不会停止后台服务，也不会删除已落盘资料。
为什么展示端没有“登记扫描件”，离线也看不到本机附件？
展示端只读。登记及修改进入控制后台的“资料登记”，在交互预览中操作；实际文件存取需要本地服务。界面 JSON 与导出的单个 HTML 不包含扫描原件，跨电脑应复制整个交付目录及 data/documents。

这是单机本地界面控制后台，包含磁盘草稿、发布和版本记录；未接入多人账户、角色权限及远程项目业务接口。原施工工序与模拟演示保持原样；资料记录现按五分支、34 个目录管理真实本机扫描件。

三维场景仍是程序化示意模型。后台可调整 UI、内部文字、图形说明和对象展示数据；它不是 BIM 建模工具，不能用 UI 属性修改真实模型几何、材质或测绘坐标，也不会由文案修改生成现场审批、验收或设备控制结果。

验收提示引用原工序表所列名称，适用条款和指标待项目确认；本轮未纳入两份规范开展合规核验，不据界面文字宣称符合规范。

底部“施工阶段与工序定位”仅在“施工模拟演示”显示；“施工管理辅助”和“施工资料记录”不显示，中央展示区域自动扩展。
