## 原文与功能

- 浏览器实测引用 → PDF 第 37 页（文件页码）→ 9.5.10 条黄色高亮，已目视核对。下一页可正常显示，解析文字同步切换。
- PDF 采用 Range 请求，文字侧只读取目标页附近片段；无需先下载整份大 PDF。
- 持久化 FTS 测试验证重启复用、文档范围过滤、坐标保留，以及每次检索不重读 canonical 文档文件。
- 回答模式测试验证严格无命中时不调用模型、智能有命中时禁止常识补充、无关新话题不继承旧的工程检索词、通用模式跳过检索、流式 delta 和计时。
- 引用编号越界与无引用结论会在最终回答中被拦截。该检查不等于每条事实都已获得语义证明；适用性、数值和解析质量仍需原文核对。
- 稀疏文字/水印 PDF 转 OCR；复杂表格不宣称已获得结构化识别，支持 OCR 重解析。
