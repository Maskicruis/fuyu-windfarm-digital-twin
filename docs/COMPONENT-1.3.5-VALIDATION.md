# SpecFlow 知识组件 1.3.5 验证记录

本版修复 Windows PowerShell 5.1 解压深层引擎文件失败的问题，避免目标路径再追加临时文件名后超出旧环境的路径处理限制。解压改用 Windows 原生 Unicode 扩展路径接口，不依赖 LongPathsEnabled 注册表设置，无需管理员权限。

- 75 项 Node 测试通过，包含长中文/空格路径、重复安装、写入失败保留旧文件、临时文件清理、UTF-8 错误和 ZIP 路径边界校验。
- 最终 1.3.5 EXE 独立验证通过：连续上下文、SSE 思考/回答事件、原文页码与坐标、PDF Range、单实例，以及设置/会话/端口在重启后保留。
- 程序与 PDF 模块在临时解压目录移走后仍可访问。
- 已在较长的中文与空格目录中从空文件夹安装全部五个资源 ZIP，默认 71 份规范均已预解析，追加 PDF 可用；内置引擎已实际完成 OCR。

完整八页 OCR 检查点及离线安装机器可读结果将在正式 Release 发布前补齐到 VALIDATION-RESULTS.json。本次只更新独立知识组件，数字孪生主程序仍为 V0.9.4。

## 已失败的 1.3.4 如何恢复

将 1.3.5 EXE 放到原目录，保留五个资源 ZIP 和 workspace，重新双击即可继续安装。不要先删除 API 设置、会话或已有规范文件。不需要重新下载未损坏的资源 ZIP。
