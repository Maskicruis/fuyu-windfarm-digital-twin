# 知识组件 1.3.0 · 完整资源交付

日期：2026-11-03。数字孪生主程序仍为 V0.9.4，知识组件独立发布。

本版本预置用户提供的 71 份施工验收规范原件、已解析内容和 SQLite 检索索引。已解析数量以交付清单及运行界面为准；尚未完成的文件自动进入 OCR 队列，不把“原件已导入”表述为“已完成全文检索”。

默认解析所需 CPython 3.12.7、MinerU 3.4.5、CPU PyTorch、中文 OCR、版面和表格模型随资源包发布。新机器不需要已安装的 Python、Anaconda、MinerU 或用户模型缓存。高级公式/VLM 使用外部引擎扩展，默认 pipeline 解析不依赖这些模型。

EXE 内置固定版本的资源校验清单。首次启动自动下载缺失资源并校验 SHA256，或读取用户预先放在同目录的离线资源包，然后显示解压进度。再次启动复用资源。文件缺失、校验不符会明确报错，不继续使用损坏的资源。

资料登记和模型路径以 EXE 当前位置生成，搬移目录不会引用开发电脑的 C/G 盘路径。升级保留用户配置和历史记录，预置资料按 ID 去重。发布包包含 `engines`、`database/manifest.json`、`workspace/资料库`，不包含 `workspace/data` 下的 API 密钥、会话、聊天图片和设置。第三方许可随引擎保留，规范原件保留出版信息；项目 MIT 许可不对规范和模型重新授权。

验收包括数据去重与配置保护、移动路径、资源完整性、最终 EXE 隔离运行及纯扫描 PDF 的离线 OCR。具体运行结果和文件校验值见本机交付记录与 GitHub Release 附件。

53 项自动测试通过。独立 CPython 的模块搜索路径仅包含随包的 Python 标准库与 site-packages，不包含 Anaconda、开发电脑虚拟环境或用户 site-packages。阻断外部 HTTP(S)、仅放行本机解析服务通信的测试中，纯扫描 PDF 正确识别三行中文与 5℃ 数值；表格扫描 PDF 生成 1 个结构化表格，表格内容核验通过。默认 CPU pipeline 的 OCR、版面和表格解析均从随包模型加载。

兼容修复：在实际 G 盘中文安装目录运行长中文段落语言识别，验证成功及异常时工作目录均还原；FastText 模型由本地相对文件名加载。OCR 窗口/子步骤到达 100% 后不会令文档提前显示完成，只有解析、打包与索引均结束才标记就绪。
