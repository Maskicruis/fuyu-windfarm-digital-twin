# 独立知识组件 1.3.7：安装并重启的 Windows 交接修复

## 原因与改动

在真实便携 EXE 内点击更新时复现安装助手提前以退出码 0 结束。进一步独立回归确认：`child_process.spawn` 使用 `detached: true` 启动 Windows PowerShell 时，进程可退出 0 但未执行脚本。旧版仅等待 spawn 事件后关闭旧窗口，无法确认助手是否真的工作。

新版使用引擎随附的 pythonw.exe（缺失时 python.exe）作为独立 GUI 后台中继。中继用 CREATE_NO_WINDOW 运行 PowerShell，不要求安装系统 Python。旧程序收到本次请求的助手就绪回执后才退出；助手等待旧主进程和便携启动器退出，核对 SHA256、安装并以正常交互窗口启动新版。新版服务就绪且窗口可见后写入随机请求标识的回执，助手此时才记录成功。

准备失败时旧窗口保持运行、安装状态可重试。启动失败不会提前记录成功；旧进程已退出且新启动器也已结束时尝试重新打开旧 EXE。日志保存在 workspace/data/updates/install.log、helper-console.log、last-result.json。

## 验证范围

- 82 项 Node 测试通过。
- 可复现回归：直接分离启动 PowerShell 返回 0、脚本未执行；内置 Python 中继返回 0、同一脚本已执行。
- 两个真实便携 EXE 交接通过：源 EXE 是受控更新驱动（仅替换网络响应），目标为最终未修改的 1.3.7 EXE；调用真实渲染器 IPC 检查、下载全部最终 EXE 字节、安装、关闭旧启动器，确认新服务为 1.3.7、窗口可见、配置与历史保留，总耗时 32.5 秒。本测试不代表公网下载速度。
- 缺少窗口启动回执不会标记成功，校验错误被拒绝，旧 EXE 回退和配置保留测试通过。
- 最终 EXE 独立验证：流式思考/回答、连续上下文、原文 PDF 定位、设置/会话/端口重启保留及持久运行目录通过。
- 本版未更改五个解析/规范资源 ZIP，沿用 1.3.6 的完整离线安装和真实 OCR 验证。没有声称本版重做一次三 GB 资源安装。

## 旧版如何获得修复

1.3.6 及更早版本的安装器已经有问题，关闭后无窗口时需要先手动运行一次 1.3.7 EXE。保留五个资源 ZIP、engines 和 workspace，不必重新下载规范库。此后在线安装使用新中继与启动确认协议。
