# 独立知识组件 1.2.0 验收记录

日期：2026-11-02。本次针对独立桌面启动、全库协同检索修订；数字孪生主程序维持 V0.9.4。

## 修复与检索范围

- 原后台参数 `--headless` 同时被 Chromium 解释，可能造成窗口不可见。现使用 `--background`，移除旧参数的 Chromium 副作用，并隔离后台与界面的浏览器配置目录。每个数据目录仍只有一个后台写入者。
- 界面三种回答模式保留，规范/智能问答始终发送 `searchScope:all`，旧会话的单文件、分组范围不再限制检索。
- 查询从每份已索引文档召回候选，按相关性过滤后跨文档轮询分配上下文；先覆盖相关文件，再补充同文件更多片段。模型按主题协调证据，区分适用对象、差异和未覆盖事项。
- 编号条文的后续子项可跨页展开，保留首块的原文定位锚点，并标出跨页续文；原始解析文件不被修改。

## 本机实际资料测试

源目录含 71 份 PDF、约 2.22 GB。采样时 49 份完成索引，22 份仍在 OCR；未完成资料不会被声称已参与检索，解析就绪后自动加入。

实际问题为“比较混凝土养护的温度控制、养护时间和试验检验要求，按适用对象分别说明”。三次全库检索耗时 1694.8 / 706.5 / 777.6 ms。32 个入模证据片段覆盖 27 份相关文件，包含风电机组基础、线路、通用混凝土和土建验收规范。实际 DeepSeek 回答分别引用适用对象，包含风机基础低于 5℃不得洒水及相关养护时间条文。

此处“全库检索”指查询全部已索引文件，而非把每页全文同时输入模型。模型及网络延迟另计，以上为本机样本而非性能承诺。相关性与引用编号检查不能证明每句话语义正确，重要数值应点击原文复核。
