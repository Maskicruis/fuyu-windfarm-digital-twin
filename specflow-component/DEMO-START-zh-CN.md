# 主管演示快速开始 · SpecFlow 知识组件 1.3.2

[打开完整下载页](https://github.com/Maskicruis/fuyu-windfarm-digital-twin/releases/tag/component-v1.3.2)

## 1. 下载并运行

下载本页 Assets 中的下面 **5 个文件**，放入同一个可写文件夹：

- `SpecFlow-Knowledge-Component-1.3.2-x64.exe`
- `SpecFlow-1.3.2-Parsing-Engine-Windows-x64.zip`
- `SpecFlow-1.3.2-Default-Database-01.zip`
- `SpecFlow-1.3.2-Default-Database-02.zip`
- `SpecFlow-1.3.2-Default-Database-03.zip`

双击 EXE，等待首次资源校验与解压。不要手动拆开或改名这些资源包。Windows x64；建议至少预留 12 GB 磁盘空间。无需另外安装 Python、MinerU、中文 OCR 或默认解析模型。只下载 EXE 也可联网自动获取资源；演示前建议提前下载全部 5 个文件。

## 2. 查看预置规范

进入「文档数据库 → 施工验收规范」。默认有 **71 份 PDF 原件**；发布快照中 **66 份已经解析并建立检索索引**，其余 5 份可阅读、继续后台 OCR。尚未解析的资料不会作为问答证据。完整目录随 Release 的 `DEFAULT-DATABASE-CATALOG.csv` 提供，也可在源码的 presets 目录直接查看。

可先打开任意已入库规范的「阅读原文」，确认阅读器可用。无需等待整个 OCR 队列结束即可演示。

## 3. 配置模型并演示问答

在「设置 → 模型接口」填入自己的 API 地址、密钥及服务商支持的模型名称，保存并测试连接。密钥和聊天记录仅保存在本机，不随公开下载提供。

1. 打开「知识库问答」，选择「严格规范」。提问：**请综合数据库中与混凝土养护有关的规范，分别说明不同适用对象的养护要求，并列出原文依据。**
2. 观察检索范围与引用来源，等待流式回答。首次模型响应速度受接口与网络影响。
3. 点击回答中的引用，跳转原 PDF 对应页面；核对适用范围、条文和页码。PDF 文件页码可能不同于印刷页码。
4. 继续追问：**这些要求分别适用于哪些工程或环境条件？请沿用刚才的资料说明。** 检查上下文连续性。
5. 切换「通用模型」或「智能回答」，对比其回答模式。严格规范模式在依据不足时应明确说明。

## 4. 追加自己的材料

在「文档数据库 → 导入文档」选择 PDF，也可用「导入规范文件夹」批量追加。可建立自己的分组。导入和解析状态会显示在列表中，成功后自动加入全库检索；不会替换原有默认规范。

## 演示边界与数据保存

软件独立运行，不需要数字孪生主程序。解析、检索和原文阅读可离线运行；在线模型问答需要有效 API 和网络。问答只使用当前已入库的资料，不代表所有原件都已完成 OCR；引用品质应结合原文核对。

自己的资料、索引、设置和对话保存在 EXE 同目录的 `workspace` 中。升级前可备份整个 `workspace`；不要把它上传到公开 GitHub。
