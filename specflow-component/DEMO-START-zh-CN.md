# 主管演示快速开始 · 1.3.3

[完整下载页](https://github.com/Maskicruis/fuyu-windfarm-digital-twin/releases/tag/component-v1.3.3)

1. 下载该页 EXE 和全部 5 个资源 ZIP，放在同一文件夹，双击 EXE。首次自动校验并解压；也可仅运行 EXE 联网自动下载。无需另外安装解析软件或模型。
2. 「文档数据库 → 施工验收规范」自带 71 份原件，全部已预解析。可先直接打开原文，再到「设置 → 模型接口」配置自己的 API。
3. 在「严格规范」模式提问：**请综合数据库中的相关规范，分别说明不同适用对象的混凝土养护要求，并列出原文依据。**
4. 点击回答引用，跳转对应 PDF 页并查看高亮；继续追问适用条件，演示上下文连续问答。
5. 追加自己的 PDF，观察解析与索引状态；原有 71 份规范仍保留。
6. 「设置 → 组件更新」可检查并下载知识组件的新版本，校验后安装重启。

原文阅读会完整读取当前 PDF，再解码、定位；读取、渲染和模型响应是独立步骤。PDF 文件页码可能不同于书籍印刷页码。在线模型需有效 API；本地检索、阅读和解析无需联网。所有 API 密钥、会话与个人资料保存在本机 workspace 中，不随公开下载提供。
