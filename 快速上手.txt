扶余一号 · 展示前端与控制后台 V10.0

两个交付物
1. frontend.html：纯展示前端，保留模型浏览、工序查看、资料查询与原件预览；无后台入口、登记按钮或修改登记功能。
2. admin.html：独立三栏控制后台，可编辑每个组件的位置、内部文字、样式和对象展示数据；通过“资料登记”管理真实扫描件。

新增：全场播放与系统设置
1. “项目全览”右上角“播放场景”：镜头缓慢巡游，风机叶轮转动；再次点击暂停。切换工程、手动操作、打开设置或隐藏页面会暂停。施工模拟保持独立。
2. 前台和后台顶部“设置”：填入自己的 DeepSeek API Key，选择模型并保存，再“测试已保存配置”。未配置密钥时不能进行真实模型对话。
3. 悬浮智能体支持连续追问，自动带入当前工程、对象、位置、工序、示意进度和工序资源/工艺/质量参考；切换上下文停止旧请求，避免旧回答串入。
4. 密钥由 Windows DPAPI 加密保存在本机用户目录，不进入交付文件；普通参数在data/settings.json。移动项目路径或更换Windows账户后需重新填写密钥。
5. 已完成会话保存在本机，可从会话列表恢复；不会自动上传扫描件原件。“停止”结束本页等待，已提交请求可能仍在服务端完成。

推荐启动
1. 双击“启动控制后台.cmd”，脚本自动打开实际后台地址，通常不用手填 URL。
2. 启动器精确校验 revision 10.0 和当前工作目录，只复用同一目录的当前版本服务，不复用旧服务。
3. 默认尝试 8779；端口占用时自动尝试 8782–8791。现场展示双击“打开前端展示.cmd”。
4. 画布会自动重试连接；18 秒未回应显示错误与“重载画布”，已保存草稿保留。
关闭浏览器不会停止本地后台服务；再次启动可复用符合上述校验的服务。

界面编辑
1. 选择单位工程、施工模拟演示 / 施工管理辅助 / 施工资料记录和画幅。
2. 在“选取与编辑”下，从画布或组件树选择整卡、内部控件或文字；用组件 / 文字 / 全部及文字搜索查找。
3. 拖动选中边框移动，拖动右下角缩放。右侧“布局 / 样式 / 内容 / 数据”可输入精确数值。
4. 场景工具条等浮窗可选“独立定位到画布”；内部标题与按钮适合“相对父组件”。
5. “内容”可改标题、按钮、说明、数字、表格、SVG文字和输入提示。修改前确认“共享文案 / 当前对象与工序”作用范围。
6. “数据”可改当前对象名称、位置、实际与计划进度、已报工序和状态；进度数字、条形与差值同步。
7. 点击“交互预览”检查业务操作；确认界面后点“发布前端”，再“打开展示”。施工模拟演示保持原样。
可用撤销 / 重做、重置所选或恢复当前页面默认设置。布局按工程、模块和屏幕类型分别保存：桌面>1200px，平板901–1200px，窄屏<=900px。

真实扫描件登记（需要本地服务）
1. 在控制后台点“资料登记”，自动进入当前单位工程的“施工资料记录”和“交互预览”；项目全览时默认进入升压站。
2. 选择归档分支和编号目录。升压站分“土建工程 / 安装工程”；对象与工序仅作为可选关联筛选，切换工序不会清空单位工程档案。
3. 点“登记扫描件”，选择 PDF / JPEG(.jpg或.jpeg) / PNG / WEBP，单文件<=40 MiB；填写名称、档号、版本、日期、对象/工序、备注并保存。
4. 台账选择文件后可预览真实原件；后台“修改登记”可改元数据。归档标记可在“已登记 / 已标记归档”间切换，是可逆标记，不是审核或验收结论。
5. 需编辑界面布局时切回“选取与编辑”。展示前端仅查询及预览，没有登记和修改按钮。

资料归档目录
五分支合计34个目录，编号各自从00开始：
- 风力发电机组工程：7类。
- 场内交通工程：5类。
- 集电线路工程：8类。
- 升压站土建工程：7类。
- 升压站安装工程：7类。
具体目录见《使用说明.html》。未配置应交资料清单，不计算齐套率；扫描页序、清晰度、完整性和签章由人工核查。

保存与发布要分清
- UI布局、文字、样式和对象展示数据：草稿自动写data/draft.json，也可点“保存草稿”；点“发布前端”后展示端才更新。
- 发布记录最多30版；恢复为草稿后需检查并再次发布。导入JSON也仅替换后台草稿。
- 扫描件与登记信息：独立保存在data/documents（index.json与blobs原件），保存即可查询，无需发布。恢复UI历史版本不回滚资料库。
- JSON导出包含界面配置与对象展示数据，不包含附件；单个导出展示HTML也不包含扫描原件。

施工管理内容归属
- 界面直观展示：计划/实际进度、阶段与位置、程序执行记录、质量通病、危大工程、验收标准。
- 独立悬浮智能体对话：施工资源（劳动力、材料、机械、设备）、标准工艺、质量要点；每项内容保留一个入口。
- 原工序表未单列质量通病库，初始“通病名称 / 表现与部位 / 防治措施”均待配置，可在后台“内容”按工序编辑。
- 验收依据为原表引用名称，指标与适用条款待项目确认。本轮未纳入两份规范开展合规核验，不宣称规范符合性。

离线与迁移
- 双击admin.html可离线编辑UI；“导出展示前端”下载带配置的纯展示HTML，不自动覆盖G盘原文件。
- 扫描件上传、持久化及原件存取需要本地服务，离线HTML不具备资料库。
- 备份/迁移建议复制整个交付文件夹，保留完整data（尤其data/documents）、两个HTML及展示配置.json。
- V10.0界面配置仍用version:2，不直接兼容V8旧布局JSON。

本版为单机本地后台，未接多人权限或远程业务接口。三维为程序化示意，后台调整UI与展示内容，不是BIM几何编辑器。资料状态不代替现场审批和验收。
