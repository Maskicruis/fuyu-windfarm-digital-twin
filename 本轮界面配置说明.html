V11.0 · 工程知识库、引用与流式对话

前台顶部“知识库”支持导入 PDF、TXT/MD、DOCX、XLSX 和图片，按工程、分组、对象及工序关联。关闭资料窗口后后台仍继续解析；失败或缺少引擎会明确显示。扫描资料需要在“解析设置”配置本机 MinerU。

同一悬浮智能体支持资料增强、仅资料库检索和通用对话。回答与 API 返回的思考内容实时逐段显示；思考区可折叠查看，未返回思考时不补造内容。已完成会话保存在本机，可从“本机对话”恢复。

点击引用先核对文档、解析版本、内容块与页码。PDF 使用本机 PDF.js 阅读器显示实际页面，有有效坐标时高亮原文，支持缩放、翻页和“返回引用”；文字和 Office 资料定位对应解析片段。失效引用提示重新检索，不跳到同页首段。资料有效关联场景对象时，可明确点击“定位工程对象”跳转。

后台“系统管理”提供服务概览和数据接口配置。GET JSON 接口经测试及字段校验后仅应用到草稿，检查发布后才影响展示。GitHub 管理完整程序、源码和文档，不提交运行 data、导入原件、索引、会话或密钥；迁移更新时务必保留 data 和 lib。

真实 DeepSeek 连接与思考、回答流式输出已验证。自动测试数量及浏览器原文定位验收结果见同目录 V11.0_交付验证记录.json；实际 OCR 环境需另行安装验证。项目与更新说明见 README.md。

场景播放与 DeepSeek 设置

项目全览右上方点击“播放场景”，全场镜头开始缓慢巡游，风机叶轮同步转动；再次点击暂停。手动操作、切换工程、打开设置或隐藏页面会暂停，重新播放需主动点击。此控制独立于施工模拟，不改变工序和现场填报。

前台、后台顶部均有“设置”。通过启动脚本打开本机服务，在设置中填写 DeepSeek API Key，选择模型并保存，然后点击“测试已保存配置”。默认使用 DeepSeek Flash，也可切换 DeepSeek V4 Pro；可配置回复长度、记忆轮数、温度、深度思考及是否自动带入场景上下文。模型接入方式参考 DeepSeek 官方接口文档。

悬浮智能体自动跟随当前单位工程、对象位置、所查看工序，携带对应工序表的施工资源、工艺、质量要点及已配置进度；可围绕上一条回答继续追问。切换对象或会话会停止本页旧请求，避免迟到回答混入当前范围。危大工程、验收标准、质量通病继续通过界面直观提示查看。

DeepSeek 密钥使用 Windows DPAPI 加密，保存在当前 Windows 账户的 %LOCALAPPDATA%/FuyuUIStudio/credentials/，模型等普通配置也在该目录保存，并同步到项目普通参数。刷新页面、重启服务或同账户移动项目目录后无需重填。升级自动迁移旧项目配置；清除密钥后不会从旧副本恢复。更换 Windows 账户或电脑时需重新配置密钥。外部数据接口凭据按项目单独保存。

设置窗口只显示“密钥已保存”状态，不回传原始密钥；已保存时保留输入框为空即可继续使用。新安装请填写自己的 API Key，保存后测试连接。密钥不进入 G 盘交付包、HTML、布局 JSON 或浏览器存储。已完成会话可在本机对话中恢复；模型的思考独立记录，不加入下一轮历史正文。

停止按钮会中止本页流式请求；切换工程对象、资料范围或会话后，旧响应不会覆盖新对话。未配置或连接失败会显示具体提示。直接双击 HTML 的离线方式可播放场景、调整布局，模型对话与知识资料存取需要本机服务；模型连接还需要网络。

05本机扫描件能力与边界

服务模式下记录扫描件

支持上传 PDF、JPEG、PNG、WEBP，单个文件不超过 40 MiB。文件保存到本机磁盘，并建立元数据索引；选择对应归档分支和目录后，可从资料列表打开原件预览。

离线方式与资料备份

直接双击 HTML 的离线方式可进行界面编辑，但不新增扫描附件。迁移项目时应同时备份资料原件与索引；仅导出界面配置 JSON 不能代替扫描件备份。

本机资料记录不包含 OCR、自动识别页数、电子签认或资料齐套率。上传、打开原件和登记索引不等于资料已获审批或验收通过。

展示数据与实施范围

本轮不改施工模拟内容，不把工序模板数换算为实际进度。现有模型、布置和进度示例仍用于界面演示，正式项目计划、实物工程量与现场填报需按实际来源接入。

UI 文字和对象展示数据可在独立后台编辑，草稿与发布保持分开。质量通病字段待配置时保留待配置状态；危大和验收条目只展示原表参考，不据此宣称阈值合规或作出现场判定。智能体问答仍受当前已接入资料和服务能力限制，不把界面入口视为真实业务服务已经接通。

本机后台不含多人账户权限、远程项目业务接口或设备控制。三维场景仍为程序化示意，UI 编辑能力不修改 BIM 几何、真实材质或测绘坐标。

底部“施工阶段与工序定位”仅在“施工模拟演示”显示；“施工管理辅助”和“施工资料记录”不显示，中央展示区域自动扩展。
